# Release Summary

This release includes a critical hotfix addressing an important issue in both the backend and frontend. The problem arose when users selected a department; an unexpected terminal/pinpad/workstation popup would appear, which was confusing. In a previous version, there were some naming inconsistencies that have now been corrected, especially in the bulk product upload feature. We also removed some dummy data, and the system is now functioning well. Additionally, we worked on the authentication system.

---

# Hotfixes

Emergency fixes have been deployed.

**Backend**
- Refactored `category_name` to `department_name`.
- Resolved issues with Celery's naming and database configurations; using UUIDs in the database.
- Fixed order completion process to update quantity correctly on successful transactions.
- Created new utility functions for adding tracks.

**Frontend**
- Implemented department pagination.
- Added features for Top Selling items and filtering options.
- Enabled Out of Stocks filtering.
- Added Tax & Fees printing reports.
